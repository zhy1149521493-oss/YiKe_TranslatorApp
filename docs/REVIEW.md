# Code review and completed repairs

Reviewed source baseline: `de5a29a7350a3da15857cf9a28eb76b9d764df02` (v1.1.0 with audio denoising), on 2026-10-08. The repository remote matches `zhy1149521493-oss/YiKe_TranslatorApp`. The source checkout is `E:/TranslatorApp-dev`; `E:/TranslatorApp` is a separate portable runtime. The previously installed executable was not assumed to match the source baseline.

## Repair status

All eight reviewed defects have been addressed in source and the new local repair build. This is implementation/regression-test status, not a claim that every Windows device and display configuration has been tested.

| Reviewed area | Repair | Verification |
| --- | --- | --- |
| Audio restart deadlock | Snapshot the engine map before iterating; release its lock before joining capture; serialize lifecycle operations with a separate mutex and dispatch start/stop off IPC threads. | Rust tests check map availability during iteration and capture-thread join. |
| WASAPI silent packet reads | Generate zero samples for silent packets without dereferencing data; reject null non-silent pointers and invalid formats; release acquired buffers before propagating decode errors. | Null/nonzero silent data, stereo float32, float64, PCM16 and invalid-format tests. |
| UTF-8 SSE corruption | Buffer bytes until complete SSE lines/events; preserve CRLF, multiline data, reasoning/content in the same delta and EOF residual data; stop at `[DONE]`. | Every byte split and one-byte chunks, invalid UTF-8 and an actual local HTTP API-proxy integration test. |
| Queued audio final markers | Coalesce partial jobs while preserving finals, carrying source/session/utterance ID and final state. Recognition immediately finalizes history; translations update by ID/text instead of list position. | Queue tests, actual MainWindow callback/event tests, identical-text dual-source cases and browser preview. |
| Subtitle deduplication | Conservative normalized exact matching instead of character-set similarity. | Reordered sentences, repetitions and changed numbers remain distinct. |
| Source language detection | Script checks precede ASCII evidence; Latin-language hints are bounded; ambiguous input remains automatic and model prompts infer source. | Mixed Korean/ASCII, common French/Spanish and other script/Latin samples. |
| Crop bounds and monitor selection | Choose the containing monitor in physical desktop coordinates; reject invalid/cross-monitor regions and recheck captured dimensions. Primary-screen captures include their desktop origin. | Negative monitor origins, edge bounds and integer overflow tests. Hardware/DPI combinations remain untested. |
| Hung/late requests | A complete-operation 60-second deadline and cancellation guards cover all translation modes. Stop/close/settings changes invalidate queued work; OCR results return to their individual requests. | Hung-request and uncancellable-native fixtures, session invalidation, empty-page render tests and browser stop checks. |

Audio windows additionally receive only the event permissions needed for status/close notifications. Native settings/commands and the frontend must ship together because IPC result/event shapes changed; see [architecture](ARCHITECTURE.md).

## Original findings, in priority order

This table records the baseline defects and their original evidence. The behaviors below describe the pre-repair source, not the current implementation. Locations refer to functions; line numbers may shift as code changes.

| Priority | Location | Trigger and consequence | Evidence and recommended repair |
| --- | --- | --- | --- |
| P1 | `src-tauri/src/audio.rs`, `apply_sensitivity`, `apply_denoise` | Changing sensitivity for a running language, or toggling denoising while recognition runs, enters `for ... in engine().clone()`. Its temporary mutex guard stays alive through the loop. Calling `stop()` inside the loop locks the same mutex and deadlocks; subsequent audio commands can also block. | A minimal Rust 2021 probe of this exact locking pattern confirms `try_lock()` fails inside the loop after `.clone()`. Clone into a separate local statement, drop the guard, then stop/restart engines. Native audio reproduction was not attempted. |
| P1 | `src-tauri/src/audio.rs`, `capture_loop`, `GetBuffer` / `from_raw_parts` | WASAPI packet flags are obtained but ignored. A silent packet is parsed as ordinary audio; a null/invalid data pointer would violate Rust slice requirements, and undefined sample contents can enter recognition. | Code inspection and [Microsoft's capture example](https://learn.microsoft.com/en-us/windows/win32/coreaudio/capturing-a-stream) require special handling for `AUDCLNT_BUFFERFLAGS_SILENT`. Feed zero samples for silence, validate pointers for non-silent packets, and release buffers on all successful acquisition paths. No actual device packet was inspected. |
| P2 | `src-tauri/src/lib.rs`, `api_chat` SSE decoder | A Chinese UTF-8 character split between network chunks is decoded with `String::from_utf8_lossy` separately on each chunk, permanently replacing the character before the complete SSE frame arrives. | A Rust probe splitting `你好` inside its first character produces `���好`. Buffer bytes until a complete frame, or use an incremental UTF-8 decoder. Test every byte boundary, multiple frames and EOF residual data. |
| P2 | `src/App.tsx`, `submitAudioSubtitle`, `audioPendingRef` | A final utterance arriving during translation is queued as text only. Draining calls `submitAudioSubtitle(source, text)` with default `isFinal=false`, so final output is sent as the current line instead of rolling into the previous line. Late history updates also lack stable utterance identity. | An extracted-function harness of the real callback reproduces only current-line forwarding and an empty final result. Queue structured jobs with `isFinal`, utterance ID and session ID, and attach results by identity. |
| P2 | `src/App.tsx`, `similarity` | Character-set similarity ignores order and multiplicity. `你喜欢我` and `我喜欢你` score 1.0, so subtitle deduplication can suppress a different sentence. | Reproduced using the real extracted function. Use sequence-aware similarity with length checks, or conservative exact deduplication initially. |
| P2 | `src/App.tsx`, `detectLang` | Checking three ASCII letters before Korean/accented scripts classifies `한국어 test`, `Bonjour tout le monde` and `Hola amigo` as English. Automatic source/target decisions can therefore be incorrect. | Reproduced using the real extracted function. Check distinctive scripts first and clearly bound Latin-language detection, or let the model infer source language when appropriate. |
| P2 | `src-tauri/src/lib.rs`, `capture_region` | The first enumerated monitor is selected and signed coordinates are cast to unsigned without validating bounds. A restored region outside a resized display, negative coordinates, or a region on another monitor can panic instead of returning a recoverable error. | A probe linked to the project's compiled `image` dependency confirms out-of-bounds and negative-coordinate crops panic. Select the containing monitor, translate coordinates and validate/clamp bounds before calling `view()`. Actual multi-monitor capture was not tested. |
| P2 | `src/App.tsx`, local full translation and subtitle callers | Main text requests now have cancellation, but audio/screenshot/clipboard local full requests have no timeout. The audio watchdog only runs on later events and cannot cancel or identify a late result; stopping a session does not reliably isolate that result from a new session. | Inspection of fetch and caller lifecycle; a hung Ollama service was not injected. Add transport timeouts and session/utterance identity across these pipelines before relying on watchdog unlocks. |

## UI and interaction repairs included

| Before | After | Why |
| --- | --- | --- |
| Scrollbars/native controls use an inconsistent theme; system theme is sampled only when effects rerun. | Theme-specific scrollbar colors, native `color-scheme`, legacy WebView scrollbar fallback, and live system-theme listeners for main/floating/audio windows. | Scrollable settings and text areas stay consistent with light/dark appearance. |
| Subtitle restoration reads configuration before asynchronous IPC resolves. Version migration rebuilds a partial settings object. | Restore FPS, scheduler, OCR engine and region when configuration arrives; preserve unrelated settings during provider migration. | Saved choices survive restart and migration. |
| Old text requests can repaint cleared/changed input; queued work can use an old callback; switching providers does not retrigger translation. | A single-flight latest-task queue invalidates old updates immediately, retains only the newest pending work and responds to engine/provider changes. | Text, errors and loading indicators follow the current input and translation settings. |
| Tauri string rejections display `undefined`; keyboard focus is hidden; long model names/status messages overflow. | Normalize error messages, restore visible focus, truncate header labels with full titles, wrap menu/status content and allow settings navigation to scroll. | Errors remain actionable and the existing layout remains usable at the native 720 × 480 minimum size. |
| Hidden auxiliary windows initially mount the main component before switching their label. | Route directly from the native window label. | Avoid unnecessary main-window startup effects in auxiliary windows. |

## Size and maintainability

The front end has few runtime libraries; the repaired production bundle is approximately 317 kB JavaScript (97 kB gzip) and 26 kB CSS (5 kB gzip). There is no evidence that a UI framework dependency is the main source of package size.

Measured logical sizes in the existing portable folder, rounded to MiB: translation models 4265, Ollama runtime 1849, ASR models 752, OCR models 30 and WebView cache 80. `ollama-windows-amd64.zip` is another 1391 MiB; reviewed source does not reference it as a runtime input. Keep installation archives outside a distributed runtime when no longer needed. No models, caches, archives or user configuration were deleted during this review. Logical sizes are not a measurement of recoverable allocated disk space.

The main maintainability cost is concentration: the baseline `App.tsx` has 3512 lines, `lib.rs` 1879 and `audio.rs` 840. Translation routing, settings persistence and several subtitle state machines live together. Prefer staged extraction of request/session handling, configuration, provider UI and OCR/audio pipelines, with lifecycle tests first. Re-registering all global shortcuts after unrelated settings changes is also unnecessary work. A broad rewrite was not performed.
