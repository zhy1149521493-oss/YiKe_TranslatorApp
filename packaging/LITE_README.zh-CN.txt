译刻 YiKe v{{VERSION}} — Windows x64 轻量便携版

使用：完整解压 ZIP，进入文件夹，双击“译刻.exe”。请勿只复制 exe 而遗漏同包 DLL。需要 Windows 10/11 x64 和 WebView2 运行时。

本包保留文本、截图、视频字幕和双路音频翻译功能，但不包含 Ollama 本地引擎、翻译模型、OCR/ASR/降噪模型或个人配置。

1. API 翻译：设置 → 模型 → 外接 API，配置 Base URL、API Key 与模型，然后选择对应引擎。
2. 本地翻译：需完整的便携 Ollama 引擎放在程序旁的 ollama/ 目录中（其中应有 ollama.exe 及其配套 lib/），再在设置中下载/导入翻译模型。只下载模型不能代替引擎。已有完整版用户保留原 ollama/ 和 models/ 即可。
3. 截图/视频字幕：可选择 Windows 系统 OCR（取决于已安装的识别语言），或在设置 → 模型下载 RapidOCR 组件。
4. 音频：在设置 → 模型下载所需 ASR 组件；降噪模型可选。选择“同时监听”不会自动开始录音，需点击开始按钮。
5. 界面：在设置 → 常规切换诗集/工作台/经典，以及常驻导航/悬停展开。右键非编辑区域可切换主窗口置顶。

升级：先保存输入并从托盘菜单退出旧版。备份旧程序文件，用本包程序与同名 DLL 覆盖原目录；保留 config.json、ollama/、models/、ocr/、asr/。请勿删除配置后再升级。旧版与新版不能同时运行。
回退：正常退出新版，再恢复备份的旧程序与配套 DLL。旧版本可能忽略新版的部分设置字段。

从 v1.2.0 开始仅发布 Lite 包；旧 Full 包仍保留在历史 Releases 中。轻量版不表示删减业务功能。

隐私：API 模式会把待翻译文本发送给所选服务商；API Key 保存在本机 config.json。请勿把自己的配置或模型目录分享为安装包。
